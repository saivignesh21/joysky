## 🌟 Overview

JoySky is a next-generation social discovery platform inspired by stranger-chat applications but focused on safer interactions, interest-based matchmaking, and future AI-powered moderation.

Users can:

* Connect instantly with strangers
* Match based on common interests
* Exchange real-time messages
* Discover people globally
* Build meaningful conversations

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/joysky.git
cd joysky
```

### Backend Setup

```bash
cd backend
npm install
node server.js
```

Backend runs on:

```bash
http://localhost:5000
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```
